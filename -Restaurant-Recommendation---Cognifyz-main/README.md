# 🍽️ Restaurant Recommendation System

## 📌 Project Overview

The **Restaurant Recommendation System** is a Python-based project designed to provide **personalized restaurant recommendations** to users. Recommendations are generated based on preferences such as **cuisine, location, price range, and user ratings**.

The system uses **content-based filtering techniques** to analyze restaurant attributes and match them with user preferences, ensuring accurate and meaningful suggestions.

## ⚙️ Installation & Usage

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Shivendrai/Restaurant-Recommendation-System.git
cd Restaurant-Recommendation-System
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run the System

```bash
python src/recommender.py
```
