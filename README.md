## 📂 Tasks Overview

During this internship, I completed **3 out of 4 tasks** provided by Cognifyz.

### ✅ Task 1: Predict Restaurant Ratings

* **Objective**: Build a regression model to predict restaurant aggregate ratings.
* **Steps**:

  * Preprocessed dataset (handled missing values, encoded categorical features).
  * Applied regression algorithms: *Linear Regression, Decision Tree Regression*.
  * Evaluated models using **RMSE, R² Score**.
  * Interpreted results and identified most influential features (e.g., votes, location).

### ✅ Task 2: Restaurant Recommendation

* **Objective**: Create a **recommendation system** based on user preferences.
* **Steps**:

  * Cleaned and preprocessed dataset.
  * Implemented a **content-based filtering** system (using cuisine type, price range, location).
  * Tested recommendations with sample user queries.
  * Evaluated quality and diversity of recommendations.

### ✅ Task 3: Cuisine Classification

* **Objective**: Develop a **classification model** to categorize restaurants by cuisine type.
* **Steps**:

  * Data preprocessing and feature encoding.
  * Applied **Logistic Regression** and **Random Forest Classifier**.
  * Evaluated with **Accuracy, Precision, Recall, F1-Score**.
  * Analyzed performance across cuisine categories and highlighted challenges.

### 🔄 Optional Task 4 (Not Selected): Location-Based Analysis

* Perform geographical visualization and insights on restaurants by city/locality.
