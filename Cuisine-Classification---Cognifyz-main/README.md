# 🍴 Restaurant Cuisine Classification

## 📌 Project Overview

The **Restaurant Cuisine Classification** project is a **machine learning-based model** that classifies restaurants into different cuisine categories (e.g., Indian, Chinese, Italian, Fast Food, etc.) based on their attributes such as **menu items, location, price range, and ratings**.

This project demonstrates the use of **data preprocessing, feature engineering, and supervised learning algorithms** to build an accurate classification model.

## ⚙️ Installation & Usage

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Shivendrai/Restaurant-Cuisine-Classification.git
cd Restaurant-Cuisine-Classification
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run Model Training

```bash
python src/train_model.py
```

### 4️⃣ Make Predictions

```bash
python src/predict.py --input "restaurant_details.json"
```
