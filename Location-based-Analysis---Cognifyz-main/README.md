# 📍 Location-based Analysis — Cognifyz

## 📌 Project Overview

The **Location-based Analysis — Cognifyz** project performs a **geographical analysis of restaurants** in the dataset. The goal is to identify patterns and insights about **restaurant distribution, ratings, price ranges, and cuisines across different locations**.

This project uses **data visualization and exploratory data analysis (EDA)** to uncover meaningful insights about how location impacts restaurant popularity and performance.

## ⚙️ Installation & Usage

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Shivendrai/Location-based-Analysis-Cognifyz.git
cd Location-based-Analysis-Cognifyz
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Run Analysis

```bash
python src/analysis.py
```

Or open the **Jupyter Notebook** for step-by-step exploration:

```bash
jupyter notebook notebooks/location_analysis.ipynb
```

## 📊 Example Insights

* 📍 **Bangalore** has the highest number of restaurants in the dataset.
* ⭐ Restaurants in **Delhi NCR** show higher average ratings compared to other cities.
* 🍲 **North Indian and Chinese cuisines** dominate across multiple metro cities.
* 💰 Price ranges vary significantly across regions, with **Mumbai** having more premium restaurants.
